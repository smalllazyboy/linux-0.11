### //////////// 学习操作系统多进程相关修改 ////////////// ###
1.kernel\exit.c---->添加退出、主动睡眠的打印追踪
2.kernel\fork.c---->添加新建、就绪的打印追踪
3.init\main.c------>将与stdin、stdout、stderr对应的文件描述符、并创建打开log文件且建立与之对应的文件描述符的操作从init中移动到main中转换为用户态之后，也即在进程0中建立相关描述符并追踪进程
4.kernel\sched.c--->添加就绪态到运行态、主动睡眠、睡眠到就绪的状态转换追踪
5.添加process.c文件，用于测试父进程创建子进程、父进程等待子进程的退出再退出、所有子进程并行运行的功能
6.需要再kernel\printk.c中添加自定义向log文件输出内容的fprintk系统调用函数，要把该函数放在最下边，确保原包含的库可被使用
